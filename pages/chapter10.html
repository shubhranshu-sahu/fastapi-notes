6. Query Parameters

Key-Value After ? · Automatic Mapping · Default Values · Path vs Query · Flask Comparison

🔹 1. What are Query Parameters?
✅ Definition Query parameters are key-value pairs added after ? in a URL used to send additional data to the server.

🧠 Example

/items?name=abc&age=20
PartMeaning
/itemsPath
?Start of query params
name=abckey-value pair
age=20another param
&separator

✅ FastAPI Code

python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items")
def get_items(name: str, age: int):
    return {"name": name, "age": age}

🧠 How FastAPI Understands This

👉 Request: GET /items?name=abc&age=20

👉 FastAPI matches function parameters:

name = "abc"
age  = 20

👉 Output: {"name": "abc", "age": 20}

🔹 2. How FastAPI Differentiates Query vs Path
✅ Rule:
  • If parameter is in URL path → Path parameter
  • Else → Query parameter

Example

python
@app.get("/items/{item_id}")
def get_item(item_id: int, name: str):
    return {"item_id": item_id, "name": name}

Request: /items/10?name=abc

ParameterSource
item_idPath (/items/10)
nameQuery (?name=abc)
FeaturePath ParamQuery Param
LocationURL pathAfter ?
RequiredAlwaysOptional (usually)
Use caseIdentify resourceFilter/extra info
🔹 3. Default Values in Query Params
✅ Concept You can assign default values → makes parameter optional
python
@app.get("/items")
def get_items(limit: int = 10):
    return {"limit": limit}

🧠 Behavior

Request: /items (no param)
Output: {"limit": 10} (default used)
Request: /items?limit=5
Output: {"limit": 5} (user value used)
🔥 Important Rule
  • 👉 Default value = optional parameter
  • No default = required (will error if missing)
🔹 Flask Comparison ⚔️
🔵 Flask (Manual)
python
from flask import Flask, request

app = Flask(__name__)

@app.route("/items")
def get_items():
    name = request.args.get("name")
    age = request.args.get("age")
    return {"name": name, "age": age}
Problems in Flask:
  • request.args.get() → manually fetch query params
  • No automatic type conversion
  • No validation
  • Manual parsing, type casting
⚡ FastAPI (Automatic)
python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items")
def get_items(name: str, age: int):
    return {"name": name, "age": age}
FastAPI Advantages:
  • Automatic parsing
  • Automatic type conversion
  • Built-in validation
  • High code cleanliness

🧠 Interview Notes (Must Remember)
  • Query params are passed after ?
  • Automatically mapped to function parameters
  • Default values → make params optional
  • None → optional parameter
  • Path param → resource identification
  • Query param → filtering/modification
  • FastAPI auto handles: parsing · type conversion · validation
/items/1 → path param /items?limit=10 → query param /items/1?active=true → both
🔥 Common Mistakes
  • Forgetting default → making param required accidentally
  • Mixing path and query incorrectly
  • Using request.args like Flask in FastAPI
  • Not using type hints
