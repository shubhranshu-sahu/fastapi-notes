7. Optional Query Parameters

Optional[str] · None Default · Conditional Logic · Search & Filter APIs

🔹 1. Making Parameters Optional
✅ Concept If parameter is not always required → make it optional using None
python
from typing import Optional

@app.get("/items")
def get_items(name: Optional[str] = None):
    return {"name": name}

🧠 Behavior

Request: /items (no query)

👉 Output: {"name": null}

Parameter is absent → None used

Request: /items?name=abc

👉 Output: {"name": "abc"}

Parameter present → value used

🔹 2. Using None (Core Idea)
👉 None means:
  • Parameter may or may not exist
  • FastAPI will not throw error if missing

🔥 Important Insight

name: str ❌ required (will error if missing) name: str = None ✅ optional (ok if missing) name: Optional[str] = None ✅ explicit optional (preferred)
🔹 3. Conditional Logic
python
from typing import Optional
from fastapi import FastAPI

app = FastAPI()

@app.get("/items")
def get_items(name: Optional[str] = None):

    if name:
        return {"message": f"Searching for {name}"}

    return {"message": "Returning all items"}

🧠 Real Use

  • Search APIs
  • Filters
  • Conditional queries
🧠 Interview Notes (Must Remember)
  • Use Optional[str] = None for optional params
  • None = parameter may not be present
  • FastAPI doesn't error on missing optional params
  • Check if param: for conditional logic
  • Common in search endpoints and filter APIs
