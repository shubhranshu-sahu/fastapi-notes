8. Combining Path + Query Parameters

Path + Query · Pagination (skip/limit) · Search APIs · Flask Comparison · Core Routing Complete 🎉

🔹 1. Concept

You can combine both:

📌 Path Param

→ identify resource

/users/{user_id}

🔍 Query Param

→ modify/filter data

?active=true

python
@app.get("/users/{user_id}")
def get_user(user_id: int, active: bool = True):
    return {
        "user_id": user_id,
        "active": active
    }

🧠 Example Requests

Case 1: /users/1 
{
  "user_id": 1,
  "active": true   (default)
}
Case 2: /users/1?active=false 
{
  "user_id": 1,
  "active": false   (user value)
}
🔹 2. Real-World Example (Pagination)
python
@app.get("/products")
def get_products(skip: int = 0, limit: int = 10):
    return {
        "skip": skip,
        "limit": limit
    }

Request: /products?skip=10&limit=5

👉 Used in:
  • Pagination
  • Infinite scrolling
🔹 3. Multiple Query Parameters — Search API
python
@app.get("/search")
def search(q: str, page: int = 1, limit: int = 10):
    return {
        "query": q,
        "page": page,
        "limit": limit
    }

👉 Example Request: /search?q=fastapi&page=2&limit=20

Output: 
{
  "query": "fastapi",
  "page": 2,
  "limit": 20
}
🔹 4. Flask Comparison ⚔️
🔵 Flask Manual Code
python
from flask import Flask, request

app = Flask(__name__)

@app.route("/items")
def get_items():
    name = request.args.get("name")
    age = request.args.get("age")
    return {"name": name, "age": age}
  • request.args.get() → manually fetch
  • No automatic type conversion
  • No validation
  • Manual parsing + Manual type casting
⚡ FastAPI Clean Code
python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items")
def get_items(name: str, age: int):
    return {"name": name, "age": age}
  • Automatically parsed from URL
  • Auto type conversion
  • Built-in validation
  • Clean, readable code
🧠 Interview Notes (Must Remember)
  • Query params are passed after ?
  • Automatically mapped to function parameters
  • Default values → make params optional
  • None → optional parameter
  • Path param → resource identification
  • Query param → filtering/modification
  • FastAPI auto handles: parsing · type conversion · validation
/items/1 → path param /items?limit=10 → query param /items/1?active=true → both combined
