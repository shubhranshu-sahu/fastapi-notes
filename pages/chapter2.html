2. Installation

pip install · Uvicorn ASGI Server · First Minimal App · Running & Accessing

🔹 Basic Installation
bash 
pip install fastapi
🔹 ASGI Server (IMPORTANT)

FastAPI does NOT run itself — it needs an ASGI server:

👉 Install:
bash 
pip install uvicorn

Uvicorn is a lightning-fast ASGI server used to run FastAPI apps.

🔹 Full Installation (Recommended)
bash 
pip install "fastapi[all]"

This installs:

  • Uvicorn
  • Pydantic
  • Email validation
  • Other useful dependencies
🔹 Verify Installation
bash 
python -c "import fastapi; print(fastapi.__version__)"
🔹 First Minimal App
python 
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello FastAPI"}
🔹 Run the App
bash 
uvicorn main:app --reload
PartMeaning
mainfile name (main.py)
appFastAPI instance
--reloadauto restart server on code change
🔹 Access in Browser
  • API: http://127.0.0.1:8000
  • Docs (Swagger): http://127.0.0.1:8000/docs
🔹 Flask vs FastAPI (Execution)
🔵 Flask
bash
flask run
⚡ FastAPI
bash
uvicorn main:app --reload
👉 Key Difference:
  • Flask → runs with built-in dev server (WSGI)
  • FastAPI → runs with ASGI server (Uvicorn)
