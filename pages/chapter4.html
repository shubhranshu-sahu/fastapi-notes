Chapter 4

What is Async (Asynchronous Programming)?

Sync vs Async · await · Event Loop · asyncio · FastAPI Context

🔹 Definition

Asynchronous programming (async) is a way of writing code where a program can start a task and continue executing other tasks without waiting for the first one to finish.

👉 In simple words:

"Don't wait — move on, and come back when the result is ready."

🔹 Synchronous vs Asynchronous (Core Idea)
🧱 Synchronous (Blocking)

Tasks execute one after another. Each task must finish before the next starts.

python
def task():
    data = fetch_from_db()   # waits here
    process(data)            # runs after fetch completes
👉 Problem: CPU sits idle while waiting (waste of time)
⚡ Asynchronous (Non-Blocking)

Tasks can run independently. While waiting, program does other work.

python
async def task():
    data = await fetch_from_db()  # doesn't block entire program
    process(data)
👉 Key idea: await → pause THIS function, not the whole program
🔹 Real-Life Analogy ☕
☕ Synchronous
  • Order coffee
  • Stand there doing nothing
  • Wait until ready
⚡ Asynchronous
  • Order coffee
  • Sit and work on laptop
  • Get notified when ready
👉 That's async = better utilization of time
🔹 Why Async Exists

Async is useful when tasks involve:

  • Network calls (APIs)
  • Database queries
  • File I/O
  • External services (like LLM APIs)
👉 These are called I/O-bound operations
🔹 Key Keywords in Python Async

1. async def

Defines an asynchronous function

python
async def fetch_data():
    return "data"

2. await

Waits for result without blocking entire program

python
result = await fetch_data()

3. Event Loop (Concept)

  • Manages execution of async tasks
  • Switches between tasks efficiently
👉 FastAPI uses this internally via ASGI
🔹 Example 1: Without Async (Blocking)
python
import time

def fetch_data():
    time.sleep(3)
    return "data"

def main():
    print(fetch_data())
    print(fetch_data())

main()
⏱ Total time = 6 seconds
🔹 Example 2: With Async (Non-Blocking)
python
import asyncio

async def fetch_data():
    await asyncio.sleep(3)
    return "data"

async def main():
    task1 = fetch_data()
    task2 = fetch_data()

    results = await asyncio.gather(task1, task2)
    print(results)
⏱ Total time = 3 seconds

👉 Both tasks run concurrently

🔹 FastAPI Example (Important)
python
from fastapi import FastAPI
import asyncio

app = FastAPI()

@app.get("/")
async def home():
    await asyncio.sleep(2)
    return {"message": "Hello"}
👉 While one request is waiting: FastAPI can handle other requests
🔥 Flask vs FastAPI (Async Context)
🔵 Flask
  • Uses WSGI
  • Mostly synchronous
  • One request per worker (blocking)
⚡ FastAPI
  • Uses ASGI
  • Supports async natively
  • Can handle multiple requests efficiently
🔹 When Async Helps (Very Important)
✅ Use Async When:
  • Calling external APIs (like Gemini, OpenAI)
  • Database queries
  • File uploads/downloads
  • Web scraping
❌ Avoid Async When:
  • CPU-heavy tasks (e.g., ML training)
  • Pure calculations
👉 For CPU tasks → use multiprocessing instead
🧠 Interview-Level Explanation

If asked: "What is async in Python?"

Asynchronous programming allows a program to handle multiple tasks concurrently without blocking execution. It is especially useful for I/O-bound operations like API calls or database queries. In Python, we use async def to define coroutines and await to pause execution without blocking the event loop. FastAPI leverages this through ASGI to serve many requests concurrently with a single thread.
⚡ Key Takeaways
  • Async = non-blocking execution
  • await pauses function, not program
  • Best for I/O-bound tasks
  • FastAPI uses async → better performance
  • Flask is mostly sync → less efficient under load
🔥 Important Mental Shift
In Flask: One request = one worker = blocking In FastAPI: One request can pause → other requests continue
