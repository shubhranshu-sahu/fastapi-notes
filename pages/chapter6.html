2. Path Operations (HTTP Methods)

GET · POST · PUT · DELETE · REST Principles · Full CRUD Example

🔹 1. What is a Path Operation?
✅ Definition A path operation is a combination of: a URL path (like /users) + an HTTP method (GET, POST, etc.)
👉 Together, they define: "What should happen when a request is made to this URL using this method?"

🧠 Example

python
@app.get("/users")
def get_users():
    return ["user1", "user2"]
  • Path → /users
  • Method → GET
  • Operation → return users list
🔥 Important Insight

👉 Same path can have different operations:

@app.get("/users")    # Fetch users
@app.post("/users")   # Create user

👉 Path same, method different → behavior different

🔹 2. HTTP Methods (Core Concept)

HTTP methods define intent of request

MethodPurposeExample

🔹 3. @app.get() Deep Explanation
python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users")
def get_users():
    return {"users": ["Alice", "Bob"]}

🧠 Breakdown (Line-by-Line)

1. @app.get("/users")
  • @ → decorator syntax in Python
  • app.get → method of FastAPI instance
  • "/users" → path
  • Registers route in FastAPI router
  • Maps: (GET, "/users") → get_users()
2. Function get_users()

Called when request hits /users

Can be def or async def

3. Return Statement

return {"users": ["Alice", "Bob"]}

FastAPI automatically: Converts dict → JSON · Adds headers (Content-Type: application/json) · Sends HTTP response

🔹 5. @app.put() Deep Explanation
python
@app.put("/users/1")
def update_user():
    return {"message": "User updated"}
  • Used to update existing resource
  • Usually replaces entire data
  • 👉 Example: Update user profile completely
🔹 6. @app.delete() Deep Explanation
python
@app.delete("/users/1")
def delete_user():
    return {"message": "User deleted"}
  • Used to remove resource
  • Should be idempotent: Deleting again → same result
🔹 7. REST Concept (VERY IMPORTANT)
✅ What is REST? REST = Representational State Transfer. It is a design style where each URL represents a resource and HTTP methods define actions.

🧠 REST Example

ActionMethodEndpoint
Get all usersGET/users
Get one userGET/users/1
Create userPOST/users
Update userPUT/users/1
Delete userDELETE/users/1
🔥 REST Principle — Use nouns, not verbs:
❌ Wrong: /getUsers   /createUser
✅ Correct: /users
🔹 8. Full Example (Combined CRUD)
python
from fastapi import FastAPI

app = FastAPI()

# GET - Read
@app.get("/users")
def get_users():
    return {"users": ["Alice", "Bob"]}

# POST - Create
@app.post("/users")
def create_user():
    return {"message": "User created"}

# PUT - Update
@app.put("/users/{user_id}")
def update_user(user_id: int):
    return {"message": f"User {user_id} updated"}

# DELETE - Remove
@app.delete("/users/{user_id}")
def delete_user(user_id: int):
    return {"message": f"User {user_id} deleted"}

🔹 10. Important Internal Working

When you define @app.get("/users")

👉 FastAPI internally:

  • Registers route in router
  • Stores: path · method · function reference

On request:

  • matches path + method
  • executes function
  • serializes response
🧠 Interview Notes (Must Remember)
  • Path operation = URL + HTTP method
  • Decorators map routes to functions
  • FastAPI automatically converts response to JSON
  • REST uses: GET → read · POST → create · PUT → update · DELETE → remove
  • Same path + different method = different behavior
