5. Enum in Path Parameters

Restrict Allowed Values · Python Enum · str+Enum · Conditional Logic · Swagger Dropdown

🔹 1. Restrict Allowed Values (Concept)
✅ Definition Enum path parameters allow you to restrict a path parameter to a fixed set of values instead of accepting anything.

🧠 Why Needed?

❌ Without Enum (accepts anything)
python
@app.get("/models/{model_name}")
def get_model(model_name: str):
    ...  # accepts: /models/gpt
         # accepts: /models/random
         # accepts: /models/xyz123 ← invalid!
❌ Problem: No control over valid inputs. Invalid values reach your logic.
✅ With Enum (only predefined values)
/models/gpt ✅ /models/bert ✅ /models/resnet ✅ /models/random ❌ auto error
🔹 2. Using Python Enum
python
from fastapi import FastAPI
from enum import Enum

app = FastAPI()

class ModelName(str, Enum):
    gpt = "gpt"
    bert = "bert"
    resnet = "resnet"

@app.get("/models/{model_name}")
def get_model(model_name: ModelName):
    return {"model_name": model_name}

🧠 Deep Explanation — Step by Step

Step 1: Import Enum from enum import Enum

Python's built-in Enum: Used to define fixed constant values

Step 2: Define Enum Class class ModelName(str, Enum):

🔥 Why str, Enum?

  • Enum → makes it enumeration
  • str → ensures values behave like strings
  • URL parameters are strings
  • FastAPI expects string-compatible values
Step 3: Define Allowed Values 
gpt = "gpt"
bert = "bert"
resnet = "resnet"

👉 Now only these values are valid

Step 4: Use in Route def get_model(model_name: ModelName):
  • FastAPI automatically validates input
  • Converts string → Enum member
🔹 3. What Happens Internally
Request: GET /models/gpt FastAPI: 1. Extracts → "gpt" 2. Matches with Enum 3. Converts to → ModelName.gpt Response: {"model_name": "gpt"}
🔹 4. Invalid Input Handling

Request: GET /models/random

❌ Auto Response: 
{
  "detail": [
    {
      "msg": "value is not a valid enumeration member"
    }
  ]
}
🔥 Important Insight — Validation happens:
  • Before function execution
  • Automatically
🔹 5. Accessing Enum Values
python
@app.get("/models/{model_name}")
def get_model(model_name: ModelName):
    return {
        "name": model_name,
        "value": model_name.value
    }
ExpressionMeaning
model_nameEnum object
model_name.valueActual string
🔹 6. Conditional Logic with Enum
python
@app.get("/models/{model_name}")
def get_model(model_name: ModelName):

    if model_name == ModelName.gpt:
        return {"type": "LLM", "info": "Language model"}

    elif model_name == ModelName.bert:
        return {"type": "NLP", "info": "Bidirectional encoder"}

    elif model_name == ModelName.resnet:
        return {"type": "Vision", "info": "Image recognition"}

    return {"model": model_name.value}
🔹 7. Flask Comparison ⚔️
❌ Flask DOES NOT have built-in Enum validation

Flask Equivalent (Manual)

python
from flask import Flask

app = Flask(__name__)

VALID_MODELS = ["gpt", "bert", "resnet"]

@app.route("/models/<model_name>")
def get_model(model_name):

    if model_name not in VALID_MODELS:
        return {"error": "Invalid model"}, 400

    return {"model": model_name}

🧠 Explanation (Flask)

  • Accept any string
  • Manually check validity
  • Return error manually
❌ Problems in Flask
  • Manual validation
  • Repetitive code
  • Easy to forget checks
  • No automatic documentation

🔹 8. Bonus: Enum Appears in Docs

When you open /docs:

👉 FastAPI shows:
  • Dropdown with allowed values (gpt, bert, resnet)
  • Prevents wrong input from UI itself
🧠 Interview Notes (Must Remember)
  • Enum restricts path parameters to fixed values
  • Defined using Python Enum
  • FastAPI automatically: validates input · converts to Enum · returns error if invalid
  • Use str, Enum for string-based params
  • Flask requires manual validation
Normal param → accepts anything Enum param → accepts only predefined values
🔥 Common Mistakes
  • Forgetting str in class ModelName(str, Enum)
  • Comparing with string instead of Enum (== "gpt" vs == ModelName.gpt)
  • Not using .value when needed
